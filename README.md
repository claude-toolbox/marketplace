A Claude Code plugin marketplace by GY.

## Installation

```
/plugin marketplace add claude-toolbox/marketplace
```

Then install any plugin from this marketplace:

```
/plugin install <plugin-name>@marketplace
```

## Plugins

| Plugin | Category | Description |
|--------|----------|-------------|
| [github-flow-toolkit](https://github.com/claude-toolbox/github-flow-toolkit) | workflow | Complete GitHub Flow workflow: conventional commits, PR lifecycle, code review, issue triage, branch protection, and release tagging |
| [web-search-toolkit](https://github.com/claude-toolbox/web-search-toolkit) | search | Unified search toolkit: intelligent routing across WebSearch, Exa, Context7, and gh_grep |
